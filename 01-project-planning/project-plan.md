# 项目策划书

## 一、项目名称
文物会说话：铜奔马的千年独白

## 二、项目背景
本项目利用生成式人工智能技术，
将中国传统文物铜奔马设计为具有独立人格的虚拟角色。

## 三、实践目标
1. 生成文物虚拟角色形象。
2. 设计角色性格和历史背景。
3. 编写角色互动对话。
4. 生成角色语音和动画。
5. 制作完整的互动式视频。

## 四、使用工具
- GitHub：项目管理
- DeepSeek：脚本和角色设计
- 即梦：角色与场景生成
- 可灵：视频动画
- 魔音工坊：语音生成
- 剪映：视频合成

## 五、预期成果
完成一个具有文化内涵和互动性的
铜奔马虚拟角色展示视频。
